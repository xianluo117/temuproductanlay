# Temu 商品数据分析系统使用说明

## 1. 系统用途

本系统用于长期保存和分析 Temu 每日商品流量数据，支持：

- 上传 `.xlsx` 商品数据文件。
- 从文件名自动提取统计日期，例如 `20260824` 转为 `2026-08-24`。
- 提取 Excel 内嵌商品图片；失败时使用“图片URL”并缓存到本地。
- 查看经营总览、每日趋势、转化漏斗和商品排名。
- SPU 数据页支持输入多个 SPU；使用空格、英文逗号或中文逗号分隔时按 SPU 精确匹配。
- 商详支付转化率和曝光订单转化率支持表格升序、降序排序。
- 可勾选多个 SPU，使用同一操作时间、操作内容和备注批量添加操作记录；失败项不会回滚成功记录。
- 按 SPU 查看商品图片、多指标趋势、转化率趋势和逐日明细。
- 在“SPU 对比”中选择 2-5 个 SPU，对比最新共同数据日期或手动切换共同日期。
- SPU 对比提供并排商品卡、核心指标赢家与差距、转化漏斗以及多 SPU 历史趋势图。
- 按首次加入站点日期、商品指标范围和支付指标范围筛选 SPU。
- 为 SPU 新增、编辑和删除操作记录，记录操作时间、操作内容和备注。
- 记录影响全部产品的平台操作、政策变化或经营调整。
- 查看曝光、点击率、加购率、支付转化及连续无订单异常。
- 创建当前账号业务备份；管理员可另行创建完整系统备份。

## 2. 登录与角色

- 支持自主注册；自主注册账号默认为普通用户。
- 默认管理员账号为 `admin`，默认密码为 `password`。首次登录必须修改默认密码。
- 普通用户只能查看和修改自己的导入、SPU、指标、图片、操作记录、异常设置和备份。
- 管理员可在顶部选择数据账号，查看和管理指定用户的隔离业务数据。
- 管理员可在“用户管理”中设置角色、启用或停用账号、重置密码。
- 系统始终保留至少一个已启用管理员。停用账号后，其现有登录会话立即失效。
- 密码使用 `scrypt` 加盐哈希保存；登录状态使用服务端会话和 HttpOnly Cookie。
- 升级前已有的全部业务数据会自动归属默认管理员账号。

## 3. 备份权限

- “备份管理”仅备份和恢复当前数据账号，不影响其他用户。
- 每次导入前自动创建当前账号备份；自动备份保留最近 3 个自然日。
- 管理员额外拥有“系统备份”，用于备份或恢复全部账号及全部用户业务数据。

## 4. 环境要求

- Windows 11。
- Node.js 22 或更高版本。
- npm 10 或更高版本。

## 5. 启动与局域网访问

双击项目根目录中的 `start.bat`。

首次启动会自动执行以下操作：

1. 安装依赖。
2. 构建前端和后端。
3. 在所有 IPv4 网络接口上启动服务。
4. 在服务器本机打开 `http://127.0.0.1:3100`。

局域网内其他设备使用服务器电脑的 IPv4 地址访问，例如：

```text
http://192.168.1.100:3100
```

服务器电脑的 IPv4 地址可在 Windows 网络设置中查看，或在终端运行 `ipconfig` 后查看当前网卡的“IPv4 地址”。

首次从局域网访问时，需要允许 Windows Defender 防火墙放行 Node.js，或者为 TCP 端口 `3100` 创建专用网络入站规则。服务器和访问设备必须位于可互通的同一局域网，路由器不能启用客户端隔离。

请勿将端口 `3100` 直接映射到公网。本系统默认使用 HTTP，适合可信局域网；若需公网访问，应先配置 HTTPS 反向代理和额外访问控制。

请勿关闭正在运行的命令窗口。关闭窗口后服务停止。

开发调试时可运行 `dev.bat`。Vite 同样监听全部 IPv4 接口：服务器本机使用 `http://127.0.0.1:5173`，局域网设备使用 `http://服务器IPv4地址:5173`。

## 6. 每日导入

1. 打开“每日导入”。
2. 拖入 Temu 导出的 `.xlsx` 文件。
3. 核对统计日期、行数、图片数量和预检提示。
4. 点击“确认导入”。数据和 Excel 内嵌图片会先写入本地。
5. 图片 URL 随后进入后台队列，以最多 3 个并发任务下载；失败自动重试 3 次，服务重启后继续未完成任务。
6. 可在“导入记录”的图片处理进度中查看成功、处理中和失败数量。
7. 同一统计日期已有数据时，按钮会显示“确认覆盖并导入”。覆盖操作只替换该日期的流量指标，不删除 SPU 操作记录。

Excel 至少应包含以下列：

- SPU
- 图片
- 图片URL
- 首次加入站点时间
- 曝光量
- 点击量
- 访客量
- 加购人数
- 订单量
- 商详支付买家数
- 商详支付转化率
- 曝光订单转化率
- （曝光量）搜索数据

## 5. 图片规则

图片展示优先级：

1. Excel 内嵌图片。
2. 图片 URL 下载后的本地缓存。
3. 无图片占位图。

内嵌图片随数据导入立即保存。图片 URL 不阻塞数据导入，由 SQLite 持久化后台队列下载。任务最多并发 3 个，失败自动重试 3 次，服务重启后会继续未完成任务。

下载完成的图片存放在 `data/images`。断网后仍可查看已经缓存的图片。

## 6. 数据目录

- SQLite 数据库：`data/database/temu-analytics.sqlite`
- 图片缓存：`data/images`
- 原始 Excel：`data/imports`
- 备份文件：`data/backups`
- 临时文件：`data/temp`

不要在系统运行时手动修改数据库或删除数据目录。

## 7. SPU 数据筛选

在“SPU 数据”页面可组合使用以下条件：

- 首次加入站点日期范围。
- 商品情况：曝光量、点击量或商品访客数的最小值与最大值。
- 支付情况：订单量、支付买家数、商详支付转化率或曝光订单转化率的最小值与最大值。
- SPU 关键词和数据日期。

设置条件后点击“查询”。转化率范围使用百分数输入，例如 `5` 表示 `5%`。点击“重置”可清空全部数据筛选条件。

## 8. SPU 对比

1. 打开左侧“SPU 对比”。
2. 搜索并选择 2-5 个不同的 SPU。
3. 点击“开始对比”。系统默认使用全部所选 SPU 都有数据的最新共同日期。
4. 如需查看其他日期，在“比较日期”中选择其他共同数据日期。
5. 查看并排产品卡、曝光量、点击量、访客量、购物车用户数、订单量、商详支付转化率和曝光订单转化率。
6. 每项指标会标记最高值；其他 SPU 显示与最高值的差距。转化率差距按百分点显示，数量指标差距按百分比显示。
7. 转化漏斗对比展示各 SPU 在所选日期的曝光、点击、访客、加购和订单表现。
8. 历史趋势图可切换指标，每个 SPU 使用固定颜色和独立折线；没有数据的日期保持为空，不使用零值补齐。

如果所选 SPU 不存在共同数据日期，系统会提示无法进行同日对比。管理员切换数据账号后，只能对比当前数据账号下的 SPU。

## 9. 全局操作记录

1. 打开左侧“全局操作记录”。
2. 点击“新增全局记录”。
3. 操作日期时间默认使用当前电脑时间，也可手动修改。
4. 填写会影响全部产品的操作内容；备注可选填。
5. 保存后，记录按操作日期时间倒序展示。

全局操作记录支持编辑和删除，适合记录平台政策调整、全店活动、价格策略、物流设置或其他会影响全部产品的事件。

全局操作记录独立保存在 SQLite 数据库中，随完整备份一起保存和恢复，不受每日流量数据覆盖影响。

## 10. SPU 操作记录

1. 打开“商品列表”，进入目标 SPU 详情页。
2. 在“操作记录”区域点击“新增操作记录”。
3. 核对操作日期时间。默认使用当前电脑时间，也可手动修改。
4. 填写操作内容；备注可选填。
5. 保存后，记录按操作日期时间倒序展示。

已有记录支持编辑和删除。操作记录独立保存在 SQLite 数据库中，覆盖导入同一天的流量数据不会删除操作记录。

## 11. 自动备份、手动备份与恢复

### 自动备份

- 每次确认导入前，系统先备份当前完整状态。
- 同一自然日只保留最新一份自动备份。
- 自动备份保留最近 3 个自然日。
- 自动备份失败时，本次导入会被取消，不会修改现有数据。

### 手动备份

1. 打开“备份与恢复”。
2. 点击“创建手动备份”。
3. 点击“下载”，将 ZIP 文件复制到其他磁盘。

手动备份不会被 3 天自动清理规则删除。

### 恢复已有备份

1. 打开“备份与恢复”。
2. 找到目标自动备份、手动备份或恢复前备份。
3. 核对创建时间、数据日期范围和数据条数。
4. 点击“恢复”。
5. 在高风险确认窗口中再次确认。

恢复前，系统会自动创建一份“恢复前”快照。恢复将替换 SQLite 数据库、商品图片和原始 Excel。使用 `start.bat` 启动时，恢复完成后服务会自动重启，页面数秒后重新连接。

也可点击“上传备份恢复”，选择之前下载的 ZIP 文件。

备份包含：

- SQLite 数据库，包括 SPU 操作记录。
- 本地商品图片。
- 已导入的原始 Excel。
- 备份类型、创建时间、数据日期范围和记录统计。

### 导入错误后的处理

- 同一天的数据内容错误：重新上传日期相同的正确 Excel，确认覆盖即可。
- 文件名日期错误或多天数据异常：恢复到错误导入前的自动备份。
- 恢复目标不正确：可再次恢复到系统自动创建的“恢复前”快照。

操作记录随 SQLite 数据库一起备份和恢复。

## 11. 数据口径

- 点击率 = 点击量 ÷ 曝光量。
- 加购率 = 加购人数 ÷ 访客量。
- 总览支付转化率 = 商详支付买家数 ÷ 加购人数。
- 总览曝光订单转化率 = 订单量 ÷ 曝光量。
- 环比采用当前数据日与上一个已导入数据日比较，不要求日期连续。
- Excel 中的 `-` 按空值处理；计数指标空值按 `0` 处理。

## 12. 常见问题

### 无法提取日期

文件名必须包含连续八位日期，例如 `Temu商品数据_20260824_115757.xlsx`。

### 图片 URL 无法下载

系统仍会优先使用 Excel 内嵌图片。若两者均不可用，则显示占位图。

### 页面无法访问

确认 `start.bat` 窗口仍在运行，并访问 `http://127.0.0.1:3100`。

### 端口被占用

关闭占用 `3100` 端口的程序，或修改 `apps/server/.env.example` 中的端口配置并按实际环境加载。
